# Personal Expense Tracker

## About the Project
The Personal Expense Tracker is a beginner-friendly Java console application that helps users record and manage their daily expenses.

## Features
- Add expenses and categories
- Calculate total expenses
- Display expense information
- Organize spending records

## Technologies Used
- Java 21
- Object-Oriented Programming
- Git and GitHub

## How to Run
1. Install Java Development Kit (JDK) 21 or a compatible version.
2. Open a terminal in the project folder.
3. Compile the program:

   `javac ExpenseTracker.java`

4. Run the program:

   `java ExpenseTracker`
